# CV-ready project summary

## One-line title

**Telecom Network Digital Twin | Python, FastAPI, SSE, Monte Carlo Simulation**

## Recommended bullets

- Built a reproducible 27-node telecom-network digital twin with 8,127
  synthetic telemetry samples, online anomaly detection, a FastAPI/SSE live
  dashboard, and deterministic experiment artifacts.
- Reduced simulated management traffic by 63.0% and transferred bytes by 81.5%
  using adaptive delta telemetry, while explicitly quantifying the resulting
  freshness tradeoff.
- Improved macro Top-1 root-cause localization from 69.56% to 74.75% across
  4,860 noisy single-fault trials by incorporating propagation-time evidence.
- Developed temporal multi-fault correlation over 2,160 dual-fault trials,
  improving exact two-root match from 23.84% to 63.19% and achieving 94.32%
  downstream service-impact recall.

## Interview boundary

Describe this as a public engineering implementation that builds on telecom
network-management work I performed during my Jul–Sep 2024 R&D internship. The
code was independently written for the Aug 2026 public release using synthetic
topology, identifiers, parameters, and telemetry; it contains no employer or
operator IP. Do not imply production deployment, operator data access,
SNMP/Kafka integration, service-level guarantees, or real customer impact
measurements.
